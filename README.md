# Visual Search Engine

Изолированный ML-микросервис для поиска визуально похожих изображений (рекомендательная система товаров).
Проект объединяет глубокое обучение для извлечения визуальных признаков и алгоритмы машинного обучения для быстрого поиска ближайших соседей, предоставляя результаты через удобный REST API.

## Стек технологий
* **Python**
* **PyTorch (CNN)** — Transfer Learning с использованием предобученной модели ResNet18 (Feature Extractor) для генерации векторных представлений (эмбеддингов).
* **Scikit-learn** — алгоритм поиска ближайших соседей (k-NN) с использованием косинусного расстояния.
* **Pandas** — структурирование и экспорт метаданных тренировочного датасета.
* **FastAPI** — асинхронный веб-фреймворк для оборачивания логики инференса в REST API.
* **Docker** — контейнеризация проекта для удобной интеграции с основным бэкендом.
